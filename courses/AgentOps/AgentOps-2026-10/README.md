# Тема: Langfuse в AgentOps: наблюдаемость и оценка LLM-агентов

LLM-агент может отвечать медленно, дорого или неправильно, а обычные логи не показывают, на каком шаге возникла проблема. На открытом уроке развернем Langfuse у себя локально и превратим работу агента поддержки интернет-магазина в понятную трассу: запросы к модели, поиск по базе знаний, задержки и оценки качества.

## Что вас ждет на вебинаре?

1. Развернем Langfuse локально в Docker и разберем, из каких сущностей состоит трасса LLM-приложения.
2. Инструментируем агента поддержки интернет-магазина, который отвечает клиентам по правилам возврата и доставки с помощью YandexGPT.
3. Найдем проблемный запуск по трассе и добавим автоматическую оценку ответа.

## Кому будет полезно?

- ML- и AI-инженерам: чтобы быстрее разбирать ошибки и регрессии LLM-приложений.
- Разработчикам AI-агентов: чтобы видеть полный путь обращения от вопроса клиента до ответа модели.
- Инженерам платформенных и MLOps-команд: чтобы держать контур наблюдаемости и данные пользователей на своей инфраструктуре.

## Что вы узнаете по итогам вебинара?

- Как развернуть self-hosted Langfuse через Docker Compose и подключить к нему Python-приложение.
- Как собирать связанные трассы, поколения модели, метаданные клиента и сессии.
- Как находить причины неудачных ответов и добавлять автоматические оценки качества.

# Тема: Qdrant: поиск по документам с фильтрацией по метаданным

Векторный поиск находит похожие тексты, но без метаданных часто поднимает не тот документ: старую версию политики, чужой отдел или соседний тип инструкции. На открытом уроке подключим Qdrant, сравним поиск с фильтром и без, а затем отдадим найденный контекст в LLM и посмотрим, как меняется ответ.

## Что вас ждет на вебинаре?

1. Разберем, из чего состоит точка в Qdrant: вектор, payload и коллекция.
2. Загрузим корпоративные документы с метаданными и выполним поиск по сходству.
3. Добавим фильтры по payload и сравним ответы модели на одном запросе с разным контекстом.

## Кому будет полезно?

- LLM-инженерам: чтобы retrieval в RAG не подмешивал чужой контекст.
- Backend-разработчикам: чтобы встроить векторный поиск в существующий сервис с фильтрами как в обычной БД.
- Data-инженерам и ML-специалистам: чтобы проектировать payload и индексы под реальные запросы к базе знаний.

## Что вы узнаете по итогам вебинара?

- Как поднять Qdrant локально и создать коллекцию с индексами по полям payload.
- Как загрузить документы вместе с метаданными и искать ближайшие векторы.
- Как ограничить выдачу фильтром по отделу, типу документа и году и получить ответ LLM только из этого контекста.

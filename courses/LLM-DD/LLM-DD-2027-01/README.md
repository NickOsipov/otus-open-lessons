# Тема: PyMuPDF: страницы PDF в текст для базы знаний

RAG по PDF-инструкциям часто ломается еще до векторной базы: в чанки попадают колонтитулы и номера страниц, сканы превращаются в пустые строки без предупреждения, а модель отвечает без ссылки на источник. На открытом уроке снимем текст PDF по страницам через PyMuPDF, уберем лишнее и получим ответ LLM со ссылкой на конкретную страницу.

## Что вас ждет на вебинаре?

1. Откроем учебный PDF и увидим, где есть текст, а где страница-скан.
2. Снимем текст по страницам и уберем колонтитулы.
3. Сохраним страницы в файл и спросим модель по нужной странице.

## Кому будет полезно?

- LLM-инженерам: чтобы готовить PDF-документы для RAG без лишней информации в контексте.
- Python и backend-разработчикам: чтобы встроить разбор PDF в сервис с понятными метаданными источника.
- Data-инженерам и аналитикам: чтобы превращать корпус PDF в проверяемый датасет страниц.

## Что вы узнаете по итогам вебинара?

- Как увидеть, где в PDF есть текст, а где страница-скан.
- Как снять текст по страницам и убрать колонтитулы.
- Как сохранить страницы и получить ответ модели со ссылкой на страницу.

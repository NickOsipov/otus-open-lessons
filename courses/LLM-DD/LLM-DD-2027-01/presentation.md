# PyMuPDF: страницы PDF в текст для базы знаний

## Цели

После занятия вы сможете:

1. Извлечь текст PDF по страницам
2. Убрать колонтитулы из текста страницы
3. Получить ответ LLM со ссылкой на страницу

## Смысл занятия

Передавать в базу знаний и в модель очищенный текст страницы с номером источника, а не служебные колонтитулы и страницы без текстового слоя.

## Теория 1. PDF - холст, а не документ

PDF хранит не абзацы, а команды рисования: «поставь эти глифы в точку x, y этим шрифтом».

Из этого следует:

- нет понятия «абзац» и «порядок чтения» - их восстанавливает библиотека
- колонтитул на каждой странице - это просто еще один текст на холсте
- у скана нет текстового слоя: на странице одна картинка, `get_text()` вернет пустую строку

Первый вопрос к любому PDF: есть ли у страницы текстовый слой. Если нет - нужен OCR или vision-модель: PyMuPDF не распознает текст на изображении.

## Теория 2. Document, Page и get_text

PyMuPDF (`import pymupdf`) - Python-обертка над движком MuPDF. Быстрый, без внешних утилит.

Модель понятий:

- `pymupdf.open(path)` - объект `Document`
- `doc[i]` - объект `Page`, нумерация с нуля
- `page.rect` - размер страницы в пунктах (A4 - 595 x 842)
- `page.get_images()` - картинки на странице

Режимы `page.get_text(...)`:

- `"text"` - простой текст страницы
- `"blocks"` - блоки с координатами
- `"words"` - отдельные слова с координатами
- `"dict"` - полная структура: строки, спаны, шрифты, размеры

## Теория 3. Блоки и порядок чтения

Блок - кусок текста с прямоугольником `(x0, y0, x1, y1)`. Обычно это абзац, заголовок или колонтитул.

Почему блоки полезнее сплошного текста:

- по `y0` и `y1` видно, где блок на странице: шапка, тело, подвал
- блоки можно фильтровать, не разбирая текст регулярками
- `sort=True` упорядочивает блоки сверху вниз и слева направо

Ограничения: в двух колонках и таблицах порядок все равно может перемешаться. Это проверяется глазами на 2-3 страницах, а не надеждой.

## Теория 4. Лишний текст на странице

Что портит чанк для RAG:

- колонтитулы: название документа, редакция, логотип
- номера страниц: «Страница 3 из 5»
- переносы слов и разорванные строки
- пустые страницы-сканы, которые выглядят как «нет данных»

Правило удаления колонтитула из двух условий:

- блок лежит в верхнем или нижнем поле страницы
- нормализованный текст блока (цифры заменены на `#`) повторяется на большинстве страниц

Одно поле без повтора удалит полезную сноску. Один повтор без поля удалит повторяющийся заголовок раздела.

## Теория 5. Страница как единица источника

Минимальная запись страницы в JSONL:

- `file` - имя PDF
- `page` - номер страницы для человека, с единицы
- `text` - очищенный текст
- `chars` - длина текста, быстрый контроль качества
- `needs_ocr` - у страницы нет текстового слоя

Номер страницы нельзя восстановить после чанкинга. Его пишут сразу при извлечении, как метаданные в векторной базе.

JSONL удобен тем, что его можно открыть глазами, отдать в индекс и проверить скриптом.

## Теория 6. Страница в промпт модели

Контур занятия линейный: вопрос, поиск страницы, один вызов модели. Векторной базы пока нет - важно качество входных данных.

- OpenAI API через официальный SDK `openai`
- ключ `OPENAI_API_KEY` только в `.env`
- модель задается в `.env`, по умолчанию `gpt-4o-mini`

Правило промпта: отвечать только по переданной странице и указывать ее номер. Если ответа нет на страницах с текстом, модель говорит «нет в документе». Страница-скан в контекст не попадает, пока ее не распознали.

## Практика

План (совпадает с `practice.md` и `code/`):

1. Собрать учебный PDF и настроить окружение
2. Осмотреть PDF: страницы, текстовый слой, сканы
3. Извлечь текст и блоки одной страницы
4. Убрать колонтитулы и номера страниц
5. Сохранить страницы в JSONL
6. Задать модели вопрос по найденной странице

# Тема: OCR страниц PDF для базы знаний

RAG по PDF молча теряет сканы: страница-картинка дает пустой текст, и модель отвечает без нужного акта или договора, а никто не видит пропуск. На открытом уроке найдем такие страницы, отрисуем их в PNG, распознаем через vision-модель и сохраним текст с пометкой источника.

## Что вас ждет на вебинаре?

1. Найдем в PDF страницы-сканы, которые PyMuPDF читает как пустые.
2. Распознаем скан через vision-модель и проверим результат по ключевым полям.
3. Соберем страницы с источником текста и получим ответ модели по распознанной странице.

## Кому будет полезно?

- LLM-инженерам: чтобы сканы документов попадали в RAG, а не выпадали из базы знаний.
- Python и backend-разработчикам: чтобы встроить OCR в пайплайн загрузки документов с понятными метаданными.
- Аналитикам и data-инженерам: чтобы проверять качество распознавания на ключевых полях, а не на глаз.

## Что вы узнаете по итогам вебинара?

- Как найти страницы без текстового слоя и отрендерить их в PNG.
- Как распознать текст скана через SDK и сохранить результат, чтобы не платить за повторный вызов.
- Как проверить OCR по ключевым полям и правильно записать страницы.

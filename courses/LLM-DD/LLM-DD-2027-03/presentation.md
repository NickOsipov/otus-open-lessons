# OCR страниц PDF для базы знаний

## Цели

После занятия вы сможете:

1. Найти в PDF страницы-сканы и отрисовать их в PNG
2. Распознать скан через vision-модель OpenAI и проверить результат по ключевым полям
3. Сохранить распознанную страницу в базу знаний с пометкой источника текста

## Смысл занятия

Скан без OCR молча выпадает из базы знаний: модель отвечает без нужной страницы, и никто не видит пропуск.

## Теория 1. Скан - это картинка

- в PDF-скане нет текстового слоя: `get_text()` вернет пустую строку
- проверка текстового слоя - первый шаг любого пайплайна с PDF
- страницу без текста нельзя тихо пропускать: ее нужно распознать или явно пометить

## Теория 2. Три способа распознавания

- Tesseract - классический OCR, работает локально, нужен системный пакет, хуже справляется со сложным макетом
- vision-модель - читает страницу как картинку целиком, понимает таблицы и подписи, работает через API
- гибрид - движок для текста, модель для спорных мест

Сегодня берем vision-модель через OpenAI SDK. Цена: вызов API на каждую страницу, поэтому результат кэшируем.

## Теория 3. Рендер страницы: качество картинки

- страница PDF превращается в PNG через `get_pixmap(dpi=...)`
- мелкий шрифт и низкий DPI дают ошибки: `O` и `0`, `1` и `l`, серийные номера
- для A4 с обычным текстом берем 150 DPI

## Теория 4. Промпт для OCR

- задача модели - переписать текст, а не ответить на вопрос и не пересказать
- просим сохранять порядок чтения и переносы строк
- цифры, серийные номера и даты переписываются точно
- `temperature=0`: одинаковый вход дает одинаковый результат

## Теория 5. Как проверить OCR

- в демо эталон известен: считаем долю совпадения символов
- в работе эталона нет: проверяем ключевые поля (серийный номер, сумма, дата) и выборочно сверяем глазами
- ошибка OCR попадает в ответ модели, поэтому проверка - часть пайплайна, а не работа в конце

## Теория 6. Кэш и источник в метаданных

- результат OCR сохраняем рядом с картинкой: `data/ocr/page_5.txt`, повторный запуск вызова API не делает
- в JSONL у каждой страницы поле `source`: `text_layer`, `ocr` или `missing`
- номер страницы и источник пишем сразу при извлечении: после чанкинга их уже не восстановить

## Практика

План (совпадает с `practice.md` и `code/`):

1. Собрать учебный PDF со сканом и настроить окружение
2. Осмотреть PDF: текстовый слой и сканы
3. Отрисовать страницы-сканы в PNG
4. Распознать скан через vision-модель и проверить ключевые поля
5. Собрать JSONL с источником текста каждой страницы
6. Задать вопрос по распознанной странице
